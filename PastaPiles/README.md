# Pasta Piles

Authors: A. H. Bateman and D. J. White

This repository folder provides the .bgcode file to 3D print the model pile and associated back plate.

A python script is provided that analyses a "theoretical" model setup given spaghetti properties.

Additional information and the associate publication:
Bateman, A. H and White D. J. (2026) The brittle response of axially-loaded piles: Pysical models for teaching. Proceedings of the 11th International Conference on Physical Modelling in Geotechnics. Zurich, Switzerland.
